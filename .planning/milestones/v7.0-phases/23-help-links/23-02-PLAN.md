**Change 2 -- Platform guard in open-knowledge-base handler (per D-01, D-02, D-03)**

In the `open-knowledge-base` event handler, inside the `if (isModernLayout)` branch
(currently line 122), replace:

```typescript
const url = generateUrl(wikiId) ?? WIKI_URL;
```

with:

```typescript
const fallbackUrl =
  process.platform === "linux" ? LINUX_WIKI_URL : WIKI_URL;
const url = generateUrl(wikiId) ?? fallbackUrl;
```

Use double quotes for `"linux"` (codebase convention). Guard only the Linux arm; all
other platforms (Windows, macOS) fall through to `WIKI_URL`. The `else` branch
(`isModernLayout === false`) is unchanged -- it shows the in-app Knowledge Base page and
never opens a URL (per PATTERNS.md Pitfall 5).

**Change 3 -- Register shell:openUrlFailed listener (per D-04, D-05, D-06)**

Inside the existing `context.once(() => { ... })` block (line 96), after the
`open-knowledge-base` event listener (after line 133's closing `});`), add the
`onOpenUrlFailed` listener:

```typescript
(window as any).api.shell.onOpenUrlFailed((url: string) => {
  context.api.sendNotification({
    type: "warning",
    id: "open-url-failed",
    title: "Could not open browser",
    message: "Visit: {{url}}",
    replace: { url },
  });
});
```

Why `(window as any).api.shell`: The documentation extension is a bundled extension that
imports from `vortex-api`, not from `src/renderer/src/util/preloadAccess`. The preload
API is exposed on `window.api` by `contextBridge.exposeInMainWorld`. Using `(window as any)`
avoids adding a new dependency from the extension to renderer internals. This is consistent
with how the renderer accesses the preload API -- `getPreloadApi()` is just `return window.api`.

The notification fires on ANY platform where the browser fails (per D-05) -- no platform
guard. The notification `id` is `"open-url-failed"` which deduplicates if multiple opens
fail quickly (per UI-SPEC). The notification type is `"warning"` (amber, not red) per
UI-SPEC rationale. `noDismiss` is not set (defaults to false) so the user can dismiss
after copying the URL.
