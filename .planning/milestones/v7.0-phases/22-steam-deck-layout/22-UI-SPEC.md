### ONBRD-05a: Onboarding Overlay Height Fix

**File:** `src/stylesheets/vortex/dashlet.scss`
**Selector:** `.instructions-overlay.overlay-onboarding`

| Property | Before | After | Reason |
|----------|--------|-------|--------|
| `height` | `466px` (fixed) | removed | Fixed height clips below 800px viewport |
| `max-height` | absent | `calc(100vh - 80px)` | Clamps to viewport with 80px clearance for window chrome |

**Width:** `width: 600px` — unchanged.

### ONBRD-05b: Bootstrap Modal Global Fix

**File:** `src/stylesheets/vortex/dialog-steam-deck.scss` (new file)
**Import location:** `src/stylesheets/style.scss` — append after line 497 (`@import "vortex/dialog-history"`) as `@import "vortex/dialog-steam-deck";`

Rules to declare in `dialog-steam-deck.scss`:

```scss
// Steam Deck Desktop Mode (1280x800) — prevent modal action buttons
// from being pushed below the visible area at 800px viewport height.
// max-height is a no-op at typical Windows viewport heights (1024px+).
.modal-dialog {
    max-height: calc(100vh - 160px);
    overflow-y: auto;
}

.modal-content {
    display: flex;
    flex-direction: column;
    height: 100%;
}

.modal-footer {
    flex-shrink: 0;
}
```

**Scope:** Global — applies to all Bootstrap modals (CONTEXT.md D-04).
**Platform guard:** None — viewport-responsive CSS is correct on all platforms (CONTEXT.md D-07).

**Precedent pattern:** `dialog-fomod.scss` uses identical `display: flex; flex-direction: column` on `.modal-content` and `flex: 1 0%` on `.modal-body`. The new global rule mirrors that pattern at the `.modal-dialog` level.

**Discretion item — `.modal-body` overflow:** If the FOMD dialog pattern (`flex: 1 0%` on `.modal-body`) is insufficient to scroll body content within the clamped dialog, add `overflow-y: auto` to `.modal-body` as well. Planner should verify against `dialog-fomod.scss` line 14 before deciding. The contract allows this addition without re-research.
