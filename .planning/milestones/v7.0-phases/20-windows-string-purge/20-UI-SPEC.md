## Copywriting Contract

Phase 20 is entirely a copywriting phase. The contract below is the complete specification.
Executor must use these strings verbatim.

### raiseUACDialog (ONBRD-03a) — `src/renderer/src/util/fs.ts:1561`

**Guard:** `process.platform === 'linux'` ternary on the `message` field inside `options`.

| Arm | Copy |
|-----|------|
| Windows (preserved unchanged) | `'Vortex needs to access "{{ fileName }}" but doesn\'t have permission to.\nIf your account has admin rights Vortex can unlock the file for you. Windows will show an UAC dialog.'` |
| Linux (new arm) | `'Vortex needs to access "{{ fileName }}" but doesn\'t have permission to.\nIf your account has admin rights Vortex can unlock the file for you. You will be asked for your password.'` |

Sentence structure: two sentences separated by `\n`, mirroring the Windows arm format exactly.
Both arms passed to `t()` for i18n consistency.

**Buttons:** `["Cancel", "Retry", "Give permission"]` — platform-neutral, no change required.
(Source: CONTEXT.md D-01, D-02, D-03)
