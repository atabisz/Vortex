<objective>
Fix the hardlink_activator.isSupported first-run blocker and verify with tests.

Purpose: On first game activation, hardlink_activator.isSupported throws ENOENT because the staging directory has not been created yet (ensureStagingDirectory runs after getSupportedActivators). The catch block returns "not fully initialized" making hardlink appear unsupported, blocking deploy-method auto-selection. The fix: return undefined (supported) on ENOENT, deferring the device check to deploy time when the directory exists. Per D-01 and D-05, this is a surgical code fix.

Output: Green tests confirming ENOENT handling + fixed catch block in hardlink_activator/index.ts.
</objective>
