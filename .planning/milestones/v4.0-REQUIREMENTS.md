# Requirements: Vortex Linux Support — v4.0

**Defined:** 2026-04-07
**Core Value:** A Linux user can install Vortex, detect their Steam/Proton games, download mods via NXM link, and manage saves — with elevation operations that work reliably without repeated prompts

## v4.0 Requirements

### Elevation Hardening

- [ ] **ELEV-04**: User can perform repeated elevation operations in a session without being re-prompted (persistent polkit token via session-scoped polkit rule)
- [ ] **ELEV-05**: All user-triggered elevation operations (mod deployment, symlink creation, permission fixes) complete successfully on desktop Linux without crashing or hanging
- [ ] **ELEV-06**: When elevation fails on Steam Deck (no polkit agent in Game Mode), the user sees an actionable error notification with a clear recovery path

### Save Management

- [ ] **SAVE-05**: User can transfer saves between Vortex profiles on Linux (copies save files between Wine prefix paths for the active Vortex profiles)

### Case-Folding fs Wrapper

- [x] **CASE-01**: `resolvePathCase` is importable as `util.resolvePathCase` from vortex-api — Phase 14
- [x] **CASE-02**: `readFileAsync`, `writeFileAsync`, `statAsync` on Wine prefix paths automatically resolve on-disk casing before I/O — Phase 14
- [x] **CASE-03**: `watch` on Wine prefix paths resolves on-disk casing synchronously before registering the watcher — Phase 14
- [x] **CASE-04**: `PluginPersistor.resolvePluginsFilePath` workaround removed; per-callsite case resolution replaced by transparent fs shim — Phase 14

## Future Requirements

### Distribution

- **DIST-05**: AppImage delta auto-update on SteamOS immutable filesystem — deferred; needs SteamOS hardware validation

### Protocol

- **PROT-03**: NXM handler via Steam Browser overlay on Steam Deck — deferred; requires Nexus Mods web team coordination + Steam Deck hardware

## Out of Scope

| Feature | Reason |
|---------|--------|
| Steam cloud save conflict detection | Requires Valve cloud API; substantial new complexity |
| Native Linux game support (GOG, itch.io) | Separate track, deferred to v5.0+ |
| Heroic Launcher integration | Deferred to v5.0+ |
| Flatpak distribution | AppImage works; Flatpak sandbox restrictions need separate validation effort |
| ELEV-04 persistent token via PAM | PAM approach is more complex and less portable than polkit; polkit already shipped in .deb |
