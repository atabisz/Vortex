   ```typescript
   const pluginsFile = path.join(destPath, "plugins.txt");

     .ensureDirAsync(destPath)
     .then(() => fs.writeFileAsync(loadOrderFile, ...))
     .then(() => { ... return fs.writeFileAsync(pluginsFile, ...); })
     .then(() => { ... })
     .then(() => { this.mFailed = false; return fs.statAsync(pluginsFile); })
     .then((stats) => { this.mLastWriteTime = stats.mtime; return null; })
     .catch(...)
     .finally(() => { this.mSerializing = false; });
   ```

   - Original format: `phaseOne = fs.readFileAsync(loadOrderFile).then(...).then(() => fs.readFileAsync(pluginsFile));`
   - Other format: `phaseOne = fs.readFileAsync(pluginsFile);`

3. **Delete the `resolvePluginsFilePath` method** (lines ~684-710 in the unstaged diff). Remove the entire private method.
