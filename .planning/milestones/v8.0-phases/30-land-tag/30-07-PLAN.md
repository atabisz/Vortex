Body: in any file with `import Promise from "bluebird"`, the `Promise` symbol is the bluebird Promise, not the global. Body: `git push --force-with-lease=<ref>:<verified-pre-push-sha>` is mandatory when pushing via inline SSH URL (`git@github.com:user/repo.git`). Verify the SHA via `git ls-remote` immediately before pushing — drift between research and execution is the single most common cause of force-with-lease push failures.
