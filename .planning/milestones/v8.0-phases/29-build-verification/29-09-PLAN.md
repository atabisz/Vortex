## Goal

End-to-end Skyrim SE smoke passes; four screenshots captured; SYNC-34 section in `29-SMOKE-EVIDENCE.md` marked PASS; one signed docs commit pushed.

## Steps

1. **Pre-flight.**
    - Skyrim SE installed via Steam, Proton compatibility enabled.
    - Nexus Mods account ready.
    - Vortex AppImage from `~/Downloads/vortex-rc1/`.
    - Pick a small cosmetic SKSE-free mod ahead of time (HUD tweak, small texture pack, font replacer — something that's safe to install/uninstall without leaving cruft). Note the Nexus URL.

2. **Launch Vortex.** Use the AppImage (matches user-facing distribution).

    ```
    ~/Downloads/vortex-rc1/*.AppImage 2>&1 | tee /tmp/skyrim-smoke.log &
    ```

    Wait for main window.

3. **Game detection (§9 / SYNC-25).** Open the Games view in Vortex. Confirm Skyrim SE is auto-detected (game tile present, Steam path correct). If you have to manually browse to it, that's a §9 regression — capture as FAIL.
   Screenshot → `.planning/phases/29-build-verification/screenshots/skyrim-game-detection.png`.

4. **Manage Skyrim SE.** Click Manage on the Skyrim SE tile. Wait for staging path setup. Confirm no errors.

5. **NXM mod install (§6/§7a-d / SYNC-22/23).** From the Nexus Mods page for the chosen mod, click the "Mod Manager Download" button (or copy the NXM:// URL and pass to Vortex). Confirm Vortex captures the download, lands the archive in staging, runs the installer wizard (or auto-installs), and the mod appears in the Mods view as "Installed".
   Screenshot → `screenshots/skyrim-nxm-install.png`.

6. **Deploy (§3 / §4 / §10 / SYNC-19/20/26).** Hit Deploy. Confirm: hardlink deploy completes without UnsupportedOperatingSystem or "this only works on Windows" errors (§4), LOOT autosort runs (§3), gamebryo native binaries (loot/bsatk) work (§10). Mods view shows the mod as "Deployed".
   Screenshot → `screenshots/skyrim-deploy-result.png`.

7. **Launch via Proton (§8 / SYNC-24).** Either via Vortex's "Start" tool OR via Steam directly. Confirm:
    - Skyrim SE main menu loads (Proton compatibility working).
    - Vortex stays alive in the system tray (NOT quitting on game launch — §8 hide-on-spawn invariant).
    - Optional: load a save / start a new game briefly to confirm the mod is actually in-game.
      Screenshot in-game with Vortex tray icon visible → `screenshots/skyrim-in-game-tray.png`.

8. **Cleanup (optional, document either way).** Either:
    - Leave the mod installed (faster, fine for a one-shot test machine), OR
    - Purge → close Vortex → confirm staging cleanup.
      Document the choice in evidence.

9. **Append SYNC-34 section to `29-SMOKE-EVIDENCE.md`** replacing the placeholder. Include:
    - Test mod: name + Nexus URL + version
    - Step-by-step walkthrough (5 steps from §3 above) with screenshot references and any log excerpts
    - Mapping table: smoke step → playbook section → SYNC requirement (one row per the D-29-03 list)
    - Total elapsed time
    - PASS verdict
