## Goal

Boot Vortex from `v8.0/config-bucket` source via `pnpm run start`. Confirm window opens; capture log + screenshot.

## Steps

1. **Confirm starting state.**

    ```
    git rev-parse --abbrev-ref HEAD
    git status --short
    ls src/main/build/bundledPlugins/ | wc -l       # expect ≥130 from 29-03
    mkdir -p .planning/phases/29-build-verification/screenshots
    ```

2. **Run `pnpm run start` and capture output.** Run in background so the executor can inspect the log while Vortex is up.

    ```
    pnpm run start 2>&1 | tee /tmp/start-from-source.log &
    START_PID=$!
    echo "PID=$START_PID"
    ```

    Wait ~30 s for Vortex to fully boot.

3. **Confirm main window opens (manual step).** Take a screenshot of the Vortex main window. Save to `.planning/phases/29-build-verification/screenshots/start-from-source.png`. Note: `.planning/` is gitignored, so the screenshot won't be committed — referenced by relative path in the evidence file per D-29-06.

4. **Inspect boot log.**

    ```
    head -50 /tmp/start-from-source.log
    grep -iE 'extension(s)?\s+(loaded|manager|registered)' /tmp/start-from-source.log | head
    grep -iE 'fatal|unhandled|crashed|stack' /tmp/start-from-source.log | head    # expect: empty
    ```

    Confirm:
    - Extension manager loaded ≥130 extensions (look for the count line — log idiom may be `loaded N extensions` or per-extension success lines you can `wc -l`).
    - No fatal/unhandled/crash lines in the first 30 s.

5. **Close Vortex** cleanly (window close button, NOT kill -9 — clean shutdown produces a clean log tail).

    ```
    wait $START_PID 2>/dev/null
    ```

6. **Write `29-SMOKE-EVIDENCE.md`** (creating the file; later plans append). Sections:
    - `# Phase 29 smoke evidence` (header: branch HEAD SHA, timestamp, OS/Electron version)
    - `## SYNC-33 part A — pnpm run start (from source)` — boot timestamp, extension count line quoted, log excerpt (first 50 lines + the count line), screenshot reference (relative path + caption), PASS/FAIL.
    - `## SYNC-33 part B — AppImage CI build` — placeholder `_To be filled by Plan 29-07._`
    - `## SYNC-33 part C — AppImage + .deb local boot` — placeholder `_To be filled by Plan 29-08._`
    - `## SYNC-34 — Skyrim SE 5-min smoke` — placeholder `_To be filled by Plan 29-09._`

7. **Commit and push.**
    ```
    git add -f .planning/phases/29-build-verification/29-SMOKE-EVIDENCE.md
    git commit -m 'docs(29-06): SYNC-33 part A — pnpm run start boots from source'
    git log -1 --show-signature
    git push git@github.com:atabisz/Vortex.git v8.0/config-bucket:sync/upstream-v2.0.0
    ```
