## Goal

AppImage runs + .deb installs and launches → SYNC-33 part C PASS → 29-SMOKE-EVIDENCE.md updated → one signed docs commit pushed.

## Steps

1. **Confirm artefacts present.**

    ```
    ls -la ~/Downloads/vortex-rc1/
    APPIMAGE=$(ls ~/Downloads/vortex-rc1/*.AppImage | head -1)
    DEB=$(ls ~/Downloads/vortex-rc1/*.deb | head -1)
    echo "APPIMAGE=$APPIMAGE"
    echo "DEB=$DEB"
    sha256sum "$APPIMAGE" "$DEB"
    ```

    Cross-check the SHA256s against 29-SMOKE-EVIDENCE.md SYNC-33 part B section — they must match.

2. **Boot the AppImage.**

    ```
    chmod +x "$APPIMAGE"
    "$APPIMAGE" 2>&1 | tee /tmp/appimage-boot.log &
    APPIMAGE_PID=$!
    ```

    Wait ~30 s. Confirm main window opens. Take screenshot → `.planning/phases/29-build-verification/screenshots/appimage-boot.png`.

3. **Inspect AppImage boot log.**

    ```
    head -50 /tmp/appimage-boot.log
    grep -iE 'extension(s)?\s+(loaded|manager|registered)' /tmp/appimage-boot.log | head
    grep -iE 'fatal|unhandled|crashed' /tmp/appimage-boot.log | head    # expect: empty
    ```

4. **Close the AppImage cleanly** (window close button) and confirm process exits:

    ```
    wait $APPIMAGE_PID 2>/dev/null
    ```

5. **Install the .deb.**

    ```
    sudo apt install -y "$DEB" 2>&1 | tee /tmp/deb-install.log
    echo "exit=${PIPESTATUS[0]}"
    ```

    Expect exit 0 with no missing-deps. Capture full output for evidence.

6. **Verify install.**

    ```
    which vortex                          # expect: /usr/bin/vortex (or wherever .deb places it)
    dpkg -L vortex | head -20             # confirm files placed
    ls /usr/share/applications/ | grep -i vortex    # desktop entry present
    ```

7. **Launch via desktop entry.** Open the Activities/Applications launcher, click Vortex. Take screenshot → `.planning/phases/29-build-verification/screenshots/deb-install-launch.png`. Confirm main window opens.

8. **Close Vortex.** Optionally `sudo apt remove -y vortex` if you want a clean machine post-test — document the choice in evidence.

9. **Append SYNC-33 part C section to `29-SMOKE-EVIDENCE.md`** replacing the placeholder. Sub-sections:
    - **AppImage boot** — path, SHA256, boot timestamp, extension count line, no-fatal confirmation, screenshot reference, PASS.
    - **.deb install + launch** — path, SHA256, `apt install` output (full), `which vortex` result, desktop-entry path, screenshot reference, PASS.

10. **Commit and push.**
    ```
    git add -f .planning/phases/29-build-verification/29-SMOKE-EVIDENCE.md
    git commit -m 'docs(29-08): SYNC-33 part C — AppImage + .deb local boot evidence'
    git log -1 --show-signature
    git push git@github.com:atabisz/Vortex.git v8.0/config-bucket:sync/upstream-v2.0.0
    ```
