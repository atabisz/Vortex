<objective>
Wire the IPC plumbing so that when `shell.openExternal()` fails in the main process,
the URL is pushed to the renderer via a typed `MainChannels` message and exposed through
the preload bridge. This plan creates the infrastructure; the renderer listener and
notification dispatch are wired in Plan 02.

Purpose: ONBRD-06b requires surfacing the failed URL to the user. The main process
detects the failure but cannot show a Vortex notification (Redux is renderer-side).
This plan bridges that gap with a typed IPC channel.

Output: Four modified source files (ipc.ts, preload.ts, preload/index.ts, open.ts)
plus one new test file (open.test.ts).
</objective>

**1. Preload bridge** (`src/preload/src/index.ts`):

In the `shell` object (currently lines 44-48), add `onOpenUrlFailed` after the existing
`openFile` entry:

```typescript
shell: {
  openUrl: (url) => betterIpcRenderer.send("shell:openUrl", url),
  openFile: (filePath) =>
    betterIpcRenderer.send("shell:openFile", filePath),
  onOpenUrlFailed: (callback: (url: string) => void) =>
    betterIpcRenderer.on("shell:openUrlFailed", (_, url) =>
      callback(url),
    ),
},
```

`betterIpcRenderer.on` is `rendererOn` which accepts only `MainChannels` keys, so the
TypeScript compiler will validate that `"shell:openUrlFailed"` exists in `MainChannels`

```typescript
export function openUrl(url: URL): void {
  shell.openExternal(url.toString()).catch((err: unknown) => {
    log("error", "failed to open URL", { url: url.toString(), error: err });
    for (const win of BrowserWindow.getAllWindows()) {
      if (!win.isDestroyed()) {
        betterIpcMain.send(
          win.webContents,
          "shell:openUrlFailed",
          url.toString(),
        );
      }
    }
  });
}
```

```typescript
import { shell, BrowserWindow } from "electron";
import { betterIpcMain } from "./ipc";

describe("openUrl", () => {
  const mockWebContents = { id: 1 };
  const mockWindow = {
    isDestroyed: vi.fn().mockReturnValue(false),
    webContents: mockWebContents,

    vi.clearAllMocks();

    openUrl(new URL("https://example.com"));
    await vi.waitFor(() => {
      expect(betterIpcMain.send).not.toHaveBeenCalled();
    });
  });
});
```

|-----------|----------|-----------|-------------|-----------------|
| T-23-01 | Spoofing | shell:openUrlFailed channel | accept | Channel only carries the URL that main already attempted to open; no user-provided input crosses the boundary. The URL originates from `openUrl()` which is called by trusted IPC handler `shell:openUrl`. |
| T-23-02 | Information Disclosure | URL in notification | accept | The URL is already known to the user (they triggered the open action); showing it in a notification does not leak additional information. |
